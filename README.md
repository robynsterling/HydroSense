HydroSense

ESP32-Based Environmental & Soil Monitoring System

Welcome to HydroSense, a collaborative hardware and software development project focused on monitoring environmental conditions using sensors, microcontrollers, and real-time data visualization.

HydroSense is being developed as part of a hands-on mentorship experience, giving team members the opportunity to explore embedded systems, programming, electronics, and collaborative engineering.


Project Overview

HydroSense uses an ESP32 microcontroller to collect environmental measurements from connected sensors and display the results on an OLED screen.


The current development work includes:
 - Temperature Monitoring: Measures ambient temperature in Celsius and Fahrenheit.
 - Humidity Monitoring: Measures relative humidity using the DHT11 sensor.
 - Heat Index Calculation: Estimates perceived temperature using temperature and humidity readings.
 - Soil Moisture Monitoring: Measures soil moisture using a capacitive analog sensor in the combined MVP.
 - OLED Display: Displays measurements on a 0.96-inch SSD1306 screen.
 - Serial Monitoring: Outputs sensor readings to the Arduino IDE Serial Monitor.
